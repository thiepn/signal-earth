# Architectural Decision Record

| ADR | Decision |
| --- | --- |
| 001 | Three.js + Globe.gl |
| 002 | React controls UI, not high-frequency WebGL state |
| 003 | Runtime backend prohibited for V1 |
| 004 | CelesTrak OMM/JSON is canonical orbital format |
| 005 | Satellite propagation occurs in a Web Worker |
| 006 | Satellite rendering uses instancing |
| 007 | One central TimeEngine |
| 008 | Global V1 simulation window is approximately ±24 h |
| 009 | 30-day event history is not fake orbital history |
| 010 | External APIs are hidden behind provider adapters |
| 011 | IndexedDB stores provider snapshots |
| 012 | User location is ephemeral by default |
| 013 | Provider state exposes freshness |
| 014 | GitHub Pages is a hard deployment constraint |
| 015 | Forecast/propagated data is explicitly identified |
| 016 | Mobile uses sheets rather than permanent sidebars |
| 017 | Four primary V1 layers only |
| 018 | Four V1 visual modes only |
| 019 | No AI system in V1 |
| 020 | Feature growth must pass the quality gate |
